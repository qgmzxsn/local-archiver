本地归档 0.4.0 — Windows 64 位开发版

便携版：先完整解压整个文件夹，再运行 local-archiver.exe。
保留旁边全部 DLL、platforms 和 LICENSES 文件。无需另装 Qt 或 7-Zip。
程序运行全离线，不上传文件，不会运行解压出的程序。

1. 点击“打开”，或拖入本机压缩包／伪装成图片视频的压缩包。
2. 点击“解压”，选择输出目录。
3. 默认自动解开内层压缩包直到没有压缩包（最多 32 层）。
   可关闭自动解压、指定层数、逐层选择停止，或保留中间包。
   多个内层包分别存入“原包名.unpacked”目录。
4. 工具栏“密码本”可添加、修改、导入、排序和删除密码。
   先尝试本地密码本，失败再询问。新密码在验证成功后才按勾选保存。
   密码本使用 Windows 凭据管理器，最多 64 条，每条 1024 UTF-8 字节。

分卷放在同一目录，后续卷会寻找首卷，缺卷会提示文件名。
支持改后缀和在媒体尾部追加 ZIP/7z/RAR；不支持像素隐写或专有隐藏算法。
支持格式和具体限制见项目 README。

原始输入始终保留；同名文件不覆盖。错误或取消后已完成的内容可能保留。
自动解压累计大小默认上限 64 GiB，可选 4/16 GiB，累计 10 万条目。
达到大小、文件数或压缩比限制会停止；Windows 暂不创建符号链接。
分卷中间包保留整组。“添加”目前只创建无压缩 ZIP；不能创建 RAR。
