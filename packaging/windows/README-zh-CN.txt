本地归档 0.2.0 — Windows 64 位

便携版
先把 ZIP 中的整个文件夹解压出来，再双击 local-archiver.exe。
请保留程序旁边的 DLL、platforms、translations 和 LICENSES 文件。
无需安装 Qt、7-Zip、Python 或开发工具。

安装版
运行带 setup.exe 后缀的文件，按提示安装到当前用户目录即可。
开始菜单会添加“本地归档”。可在系统“已安装的应用”中卸载。

使用方法
1. 点击“打开压缩包…”或把一个本机压缩包拖入窗口。
2. 确认“解压到”后面的文件夹，需要时点击“选择…”修改。
3. 点击“开始解压”；完成后可以打开输出文件夹。
4. 如需密码，程序会弹窗询问。密码只用于本次打开，关闭或更换压缩包后清除，不写入文件。

遇到同名文件会停止，原文件保留。请选择空文件夹后重试。
解压中可以取消；已完成的文件和文件夹可能保留，当前未完成的文件会清理。
解压时关闭窗口会先请求取消，等当前操作结束后关闭。

支持 ZIP、7z、tar、tar.gz/bz2/xz/zst 和 RAR 解压。
RAR 不能创建；暂不支持分卷、伪装扩展名、嵌套穿透或密码本。
Windows 暂不创建压缩包中的符号链接。
单次输出上限 64 GiB，文件条目上限 100 万。

程序不联网、不上传文件，不会运行解压出来的程序。
本版本没有代码签名。
